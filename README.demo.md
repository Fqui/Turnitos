# 🎪 Court Booking App - Demo Version

## 🌐 [Ver Demo en Vivo](https://tu-usuario.github.io/tu-repositorio/)

Esta es una versión de demostración de la aplicación de reservas que funciona completamente en el navegador, sin necesidad de backend.

## ✨ Características de la Demo

### Negocios Disponibles

La demo incluye 6 negocios de muestra:

1. **🎾 Elite Padel Club** - Club de pádel premium con 3 canchas
2. **💆 Serenity Spa & Wellness** - Spa con servicios de masajes y tratamientos
3. **🎾 Tenis Pro Academy** - Academia de tenis con múltiples canchas
4. **✂️ The Classic Barber** - Barbería clásica con servicios profesionales
5. **⚽ Fútbol 5 La Cancha** - Canchas de fútbol 5 y 7
6. **🧘 Harmony Yoga Studio** - Estudio de yoga con clases especializadas

### Funcionalidades Activas

✅ **Navegación completa** - Explora todos los negocios  
✅ **Perfiles detallados** - Ve información completa de cada negocio  
✅ **Sistema de reservas** - Realiza reservas de prueba (se guardan en memoria)  
✅ **Calendario interactivo** - Selecciona fechas y horarios  
✅ **Mapas** - Visualiza ubicaciones en mapa interactivo  
✅ **Diseño responsive** - Funciona en móviles y tablets  
✅ **Temas claros y oscuros** - Cada negocio tiene su tema personalizado  

### Limitaciones del Demo

❌ **Sin persistencia** - Las reservas se borran al recargar la página  
❌ **Sin panel de administración** - No se pueden crear o editar negocios  
❌ **Sin subida de imágenes** - Solo se usan imágenes de URLs externas  

## 🛠️ Tecnologías Utilizadas

- **React** - Framework UI
- **Vite** - Build tool
- **Framer Motion** - Animaciones
- **React Router** - Navegación
- **Leaflet** - Mapas interactivos
- **Recharts** - Gráficos (en la versión completa)

## 📱 Cómo Usar la Demo

1. **Explorar negocios** - Navega por la página principal y explora los diferentes negocios
2. **Ver detalles** - Haz click en cualquier negocio para ver su perfil completo
3. **Hacer una reserva** - Selecciona un servicio/cancha, fecha y horario
4. **Confirmar** - Completa el formulario de reserva para ver cómo funciona el flujo
